# 옷장 예보

> 밖에 있는 시간의 체감기온으로, 내 옷장 속 옷을 골라 입는 법까지 알려 줘요.

제1회 날씨 추천 앱 공모전 출품작입니다. 로그인 없이 브라우저에서 바로 열려요.

## 무엇을 하나요
- **도시를 고르거나 내 위치**를 쓰면 Open-Meteo의 1시간 단위 예보를 불러와요.
- **오늘·내일·모레**와 **밖에 있는 시간**(예: 오전 8시~오후 8시)을 고르면, 그 시간의 체감기온만 봐요.
- **기본 추천**: 상의·하의·겉옷(또는 챙길 것) 3장을 기온별 옷차림 8단계로 골라요.
- **내 옷장 코디**: 내 옷을 종류·색·두께로 등록하면, 내 옷 중에서 오늘 입을 조합을 골라요. 포인트 색은 하나만, 비 오는 날은 밝은 하의·스웨이드·캔버스·흰 신발을 뒤로 미뤄요.
- **이렇게 입어요**: 몇 시에 겉옷을 입고 벗을지, 일교차·비·바람·자외선에 맞춰 무엇을 챙길지 알려 줘요.
- **옷장 빈 곳**: 앞으로 3일 날씨에 입을 옷이 옷장에 없는 칸을 알려 줘요.

## 판정 규칙
| 무엇 | 기준 |
|---|---|
| 상의·하의 | 밖에 있는 시간의 **최고 체감기온** 단계 |
| 겉옷 | 밖에 있는 시간의 **최저 체감기온** 단계, 바람 9m/s 이상이면 한 단계 두껍게 |
| 겉옷이 필요한 날 | 겉옷 단계가 17~19℃ 이하, 또는 20~22℃인데 일교차 8℃ 이상 |
| 비 | 강수확률 60% 이상이면 우산 + 밝은 색 하의·스웨이드·캔버스·흰 신발은 뒤로 |
| 내 옷 두께 | 두꺼움(기모·누빔)은 한 단계 추운 쪽, 얇음은 한 단계 더운 쪽 |

8단계: 28℃ 이상 / 23~27 / 20~22 / 17~19 / 12~16 / 9~11 / 5~8 / 4℃ 이하 (널리 쓰이는 기온별 옷차림 표).

## 데이터와 개인정보
- 날씨 정보: [Open-Meteo](https://open-meteo.com/) (무료, 열쇠 없음, CC BY 4.0). 화면 아래에 출처를 적어요.
- 도시 좌표는 앱 안에 들어 있어요. 내 위치는 브라우저 안에서만 쓰고, 소수 둘째 자리로 줄여 이 브라우저에만 저장해요.
- 내 옷장·설정은 이 브라우저(localStorage)에만 저장돼요. 서버·로그인·광고·쇼핑 링크가 없어요.
- 날씨를 못 불러오면 "예시 날씨로 보기"를 누를 수 있고, 그때는 화면 맨 위에 **모의 데이터예요**라고 밝혀요.

## 구조
```
index.html        화면 틀
css/style.css     스타일 (라이트·다크)
js/rules.js       추천 규칙 (순수 함수, 시험 대상)
js/icons.js       옷·날씨 그림 (직접 그린 SVG)
js/app.js         화면·저장·날씨 불러오기
tests/            규칙 시험(node:test) · 화면 점검(Playwright)
```
빌드 없이 정적 파일 그대로 올리면 돼요.

```
node --test tests/rules.test.js
node tests/e2e.js shots     # Playwright가 있으면 폰·PC 화면 캡처
```
